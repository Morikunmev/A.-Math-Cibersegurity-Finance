🔥 IDENTIDADES TRIGONOMÉTRICAS AVANZADAS 🔥

Suma, Resta, Doble y Mitad de Ángulos

🔵 VISUALIZACIÓN: α + β

🎛️ CONTROLES

30°
45°

RESULTADO:
α + β = 75°

📚 FÓRMULAS

sin(α ± β) = sin(α)cos(β) ± cos(α)sin(β)

cos(α ± β) = cos(α)cos(β) ∓ sin(α)sin(β)

tan(α ± β) = [tan(α) ± tan(β)] / [1 ∓ tan(α)tan(β)]

📊 EJEMPLOS CLÁSICOS

Operación Resultado Valor
sin(45° + 30°) sin(75°) (√6 + √2)/4
sin(45° - 30°) sin(15°) (√6 - √2)/4
cos(60° + 30°) cos(90°) 0
cos(45° - 45°) cos(0°) 1

🔵 VISUALIZACIÓN: 2α

🎛️ CONTROL

30°
Doble: 60°

⚡ ÁNGULOS RÁPIDOS:

📚 FÓRMULAS DE ÁNGULO DOBLE

sin(2α) = 2sin(α)cos(α)

cos(2α) = cos²(α) - sin²(α)

También: 2cos²(α) - 1 = 1 - 2sin²(α)

tan(2α) = 2tan(α) / [1 - tan²(α)]

45° 90° 1 0

🔵 VISUALIZACIÓN: α/2

🎛️ CONTROL

60°
Mitad: 30°

⚡ ÁNGULOS RÁPIDOS:

📚 FÓRMULAS DE ÁNGULO MITAD

sin(α/2) = ±√[(1 - cos(α))/2]

cos(α/2) = ±√[(1 + cos(α))/2]

tan(α/2) = sin(α) / [1 + cos(α)]

También: [1 - cos(α)] / sin(α)
