Teorema del Seno

Relación entre lados y ángulos opuestos en cualquier triángulo

Fórmula principal
a/sin(α) = b/sin(β) = c/sin(γ) = 2R

1
Trazar altura h desde el vértice C

Dividimos el triángulo en dos triángulos rectángulos

C /|\ / | \ a / |h \ b / | \ / β | α \ /_____|_____\ A B
2
Relacionar h con lados a y b

Aplicamos seno en cada triángulo rectángulo

Triángulo izquierdo: sin(β) = h/a → h = a·sin(β) Triángulo derecho: sin(α) = h/b → h = b·sin(α)
3
Igualar las dos expresiones de h
a·sin(β) = b·sin(α) Dividir entre sin(α)·sin(β): a/sin(α) = b/sin(β) ✓
4
Repetir para el tercer lado

Trazando altura desde otro vértice se obtiene

b/sin(β) = c/sin(γ) Resultado final: a/sin(α) = b/sin(β) = c/sin(γ) ✓
Ejercicio 1

Calcular lado b

Datos: a = 10, α = 30°, β = 60°
a/sin(α) = b/sin(β) 10/sin(30°) = b/sin(60°) 10/(1/2) = b/(√3/2) 20 = b/(√3/2) b = 20·(√3/2) b = 10√3 ≈ 17.32 ✓ Verif: 10/sin(30°) = 20 10√3/sin(60°) = 20 ✓
Ejercicio 2

Calcular lado c

Datos: b = 15, β = 45°, γ = 60°
b/sin(β) = c/sin(γ) 15/sin(45°) = c/sin(60°) 15/(√2/2) = c/(√3/2) c = 15·(√3/2)/(√2/2) c = 15·√3/√2 c = 15√6/2 ≈ 18.37 ✓
Verificación

Comprobación de ratios

Triángulo: a = 8, α = 30°, β = 45°
γ = 180° - 30° - 45° = 105° a/sin(α) = 8/0.5 = 16 b = 16·sin(45°) = 8√2 ≈ 11.31 c = 16·sin(105°) ≈ 15.45 Todos los ratios = 16 ✓
Ejercicio 3

Equilátero

Triángulo equilátero: a = 10, α = β = γ = 60°
a/sin(α) = 10/sin(60°) = 10/(√3/2) = 20/√3 ≈ 11.55 b = 11.55·sin(60°) = 10 ✓ c = 11.55·sin(60°) = 10 ✓ Los tres lados iguales ✓

✓ Cuándo SÍ usar el Teorema del Seno

→
Conoces dos ángulos y un lado (AAS o ASA)
→
Conoces dos lados y un ángulo opuesto a uno de ellos (SSA)
→
Quieres encontrar un ángulo desconocido dado dos lados y un ángulo

✗ Cuándo NO usar el Teorema del Seno

→
Solo conoces tres lados (SSS) → usar Teorema del Coseno
→
Conoces dos lados y el ángulo entre ellos (SAS) → usar Teorema del Coseno
