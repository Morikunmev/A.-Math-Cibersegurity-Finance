Teorema del Coseno

Generalización del Teorema de Pitágoras para cualquier triángulo

⚡
Si α = 90°, entonces cos(90°) = 0 y la fórmula se convierte en a² = b² + c² — ¡el Teorema de Pitágoras!
Para calcular lado a
a² = b² + c² − 2bc·cos(α)
Para calcular lado b
b² = a² + c² − 2ac·cos(β)
Para calcular lado c
c² = a² + b² − 2ab·cos(γ)

Lado a calculado
—
1
Colocar triángulo en coordenadas

A en el origen, B en el eje x, C libre

A = (0, 0) B = (c, 0) C = (b·cos(γ), b·sin(γ))
2
Aplicar fórmula de distancia de B a C
a² = (b·cos(γ) − c)² + (b·sin(γ))²
3
Expandir
a² = b²·cos²(γ) − 2bc·cos(γ) + c² + b²·sin²(γ)
4
Agrupar b²
a² = b²(cos²(γ) + sin²(γ)) + c² − 2bc·cos(γ)
5
Aplicar identidad pitagórica

cos²(γ) + sin²(γ) = 1

a² = b²·1 + c² − 2bc·cos(γ) a² = b² + c² − 2bc·cos(γ) ✓
Ejercicio 1

Calcular lado c

Datos: a = 8, b = 10, γ = 60°
c² = a² + b² − 2ab·cos(γ) c² = 64 + 100 − 2(8)(10)·cos(60°) c² = 164 − 160·(1/2) c² = 164 − 80 = 84 c = √84 = 2√21 c ≈ 9.17 ✓
Ejercicio 2

Calcular ángulo γ

Datos: a = 5, b = 12, c = 13
cos(γ) = (a² + b² − c²)/(2ab) cos(γ) = (25 + 144 − 169)/120 cos(γ) = 0/120 = 0 γ = arccos(0) γ = 90° ✓ (triángulo rectángulo) Verif: 5² + 12² = 169 = 13² ✓
Ejercicio 3

Calcular lado a

Datos: b = 5, c = 7, α = 60°
a² = b² + c² − 2bc·cos(α) a² = 25 + 49 − 2(5)(7)·cos(60°) a² = 74 − 70·(1/2) a² = 74 − 35 = 39 a = √39 ≈ 6.24 ✓
Ejercicio 4

Triángulo equilátero

Datos: a = b = 10, γ = 60°
c² = a² + b² − 2ab·cos(γ) c² = 100 + 100 − 200·(1/2) c² = 200 − 100 = 100 c = √100 c = 10 ✓ (equilátero)

✓ Cuándo SÍ usar Teorema del Coseno

→
Conoces dos lados y el ángulo entre ellos (SAS)
→
Conoces los tres lados y quieres un ángulo (SSS)
→
El triángulo NO es rectángulo y no tienes ángulos

✗ Cuándo NO necesitas el Teorema del Coseno

→
Triángulo rectángulo → usa Pitágoras directamente
→
Conoces dos ángulos y un lado → usa Teorema del Seno
→
Solo necesitas un ángulo faltante → suma de ángulos = 180°
